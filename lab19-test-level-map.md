# Lab 19 — Place Tests on the Pyramid

## Three Levels
Unit tests (fast, isolated), integration tests (components wired together), and end‑to‑end tests (full system through HTTP).

## Cost and Speed
Cost increases as you move upward; speed decreases. Unit tests are cheap and fast, integration tests moderate, end‑to‑end tests slow and expensive.

## Shape
A wide base of unit tests, a narrower middle of integration tests, and a thin top of end‑to‑end tests — forming a stable pyramid.
